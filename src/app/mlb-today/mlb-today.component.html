How to Read This Page

Projected Score
The model's expected final score for both teams based on starting pitchers, lineups, and ballpark.
Win Probability
The model's estimated chance that the picked team wins outright. Higher % = stronger lean.
Confidence
Elite (70%+), High (65–69%), Medium (60–64%), Low (<60%) based on win probability.
Odds
The moneyline odds for the picked team from consensus sportsbook lines at time of generation.

What the Model Uses

Each pick is generated by the same engine powering the scoreboard tool. For MLB, the model computes expected runs from:

Starting Pitcher FIP WHIP Lineup wOBA ISO (Isolated Power) Ballpark Run Factor

Lineups and pitchers are pulled from official sources each morning. Top picks are sorted by model confidence — the largest gap between projected win probability and the implied probability from the moneyline odds.
